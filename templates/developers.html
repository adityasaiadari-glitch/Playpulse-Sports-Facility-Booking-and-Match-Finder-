Try it with curl

# log in and keep the session cookie
curl -c cookie.txt -H "Content-Type: application/json" \
     -d '{"email":"demo@playpulse.in","password":"Demo@1234"}' \
     http://127.0.0.1:5000/api/auth/login

# book badminton tomorrow at 7 PM
curl -b cookie.txt -H "Content-Type: application/json" \
     -d '{"venue_id":1,"sport":"badminton","date":"YYYY-MM-DD","hour":19}' \
     http://127.0.0.1:5000/api/bookings

Responses & errors

Success returns JSON with 200 (OK) or 201 (Created). Errors return {"error": "...", "type": "..."} with a matching status:

StatusRaised by
400ValidationError: bad input
401AuthError: not logged in / wrong password
403PermissionDenied: not your booking
404NotFoundError: unknown id
409SlotUnavailableError / GameFullError / CancellationNotAllowedError
